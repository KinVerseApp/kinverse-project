# KV-022 - SMS Invite

## Epic
Invitations

## Summary
Send invite text messages for mobile users who prefer SMS.

## User Story
As a user, I want to sms invite so that I can successfully use the KinVerse experience.

## Description
This issue covers the implementation of sms invite within the Invitations epic. The work should include the full user flow, validation, and backend/frontend integration required for a production-ready experience.

## Acceptance Criteria
- Invite emails and texts are sent with correct content and tracking metadata.
- Accepted invites create the right account or connection state.
- Invite states are visible to the user and updated correctly.
- The feature is accessible and supports mobile-first interaction patterns.
- The feature is documented and ready for QA review.

## Definition of Done
- Code is implemented and reviewed.
- Required validations and edge cases are covered.
- The behavior is testable in the application.
- Documentation or handoff notes are updated as needed.
